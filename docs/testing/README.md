# Testing & Validation Evidence

This folder holds proof that the program compiles and runs, plus any notes from
testing each feature as it gets built.

For Milestone 1 the testing covered:

- Successful compilation with no warnings
- The main menu loop showing and looping correctly
- Input validation rejecting non numbers, values below the range, and values above the range
- View Elements listing all loaded elements
- View Compounds listing all loaded compounds with their formulas
- Guess It mode showing a random formula and correctly checking a right and a wrong guess

Screenshots of compilation and runtime are saved in the repo's `img` folder.
